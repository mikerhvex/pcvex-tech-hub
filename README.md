# PcVex Tech Hub

Crea una tienda online moderna, simple y profesional llamada "PcVex", especializada en productos de computación, componentes de PC y periféricos.

IMPORTANTE:

PcVex es una marca nueva que recién está comenzando, por lo que actualmente tendrá pocos productos. NO quiero una tienda enorme ni sobrecargada. El diseño debe transmitir que es una marca nueva, moderna, confiable y profesional.

El sitio debe estar diseñado pensando en que posteriormente será trasladado a Shopify.

OBJETIVO:

Crear una tienda sencilla donde el usuario pueda entrar, entender rápidamente qué vende PcVex, ver los productos disponibles y comprar fácilmente.

ESTILO:

- Minimalista.

- Moderno.

- Tecnológico.

- Profesional.

- Llamativo pero sin exagerar.

- Mucho espacio en blanco.

- Diseño limpio.

- Pocas secciones.

- Animaciones muy sutiles.

- Excelente experiencia en celular.

- No utilizar demasiados banners, pop-ups ni elementos innecesarios.

MARCA:

Nombre: PcVex

Crear un logotipo tipográfico sencillo y moderno utilizando "PcVex".

Debe poder reemplazarse posteriormente por un logo real.

COLORES:

Utilizar una combinación moderna relacionada con tecnología.

Principalmente:

- Blanco.

- Negro/gris oscuro.

- Un color de acento azul o celeste.

No utilizar demasiados colores.

HEADER:

Crear un header sencillo:

Logo "PcVex"

Menú:

- Inicio

- Productos

- Ofertas

- Contacto

A la derecha:

- Buscador.

- Carrito.

En celular utilizar un menú hamburguesa.

El header debe ser sticky al hacer scroll.

PÁGINA DE INICIO:

1. HERO

Crear un hero simple.

Título:

"Todo para tu PC, en un solo lugar."

Subtítulo:

"Componentes y periféricos seleccionados para mejorar tu setup."

Botón:

"Ver productos"

Utilizar una imagen tecnológica relacionada con PC/periféricos, pero mantener el diseño limpio.

2. PRODUCTOS DESTACADOS

Mostrar solamente entre 4 y 8 productos ficticios para representar cómo se verá la tienda cuando esté funcionando.

Crear tarjetas de producto sencillas con:

- Imagen.

- Nombre.

- Precio.

- Precio anterior si está en oferta.

- Etiqueta "Oferta" cuando corresponda.

- Botón "Ver producto".

No agregar demasiada información a las tarjetas.

La tarjeta de producto debe ser un componente independiente y fácil de convertir posteriormente en un componente Product Card de Shopify Liquid.

3. CATEGORÍAS

Crear solamente 4 categorías principales:

- Componentes

- Periféricos

- Gaming

- Accesorios

Cada una con una imagen sencilla y un enlace.

4. BANNER PEQUEÑO

Crear una sección promocional sencilla:

"Armá tu setup."

Texto:

"Encontrá los productos que necesitás para llevar tu PC al siguiente nivel."

Botón:

"Ver productos"

No hacer un banner gigante.

5. CONFIANZA

Crear una pequeña sección con 3 beneficios:

- Compra segura.

- Envíos.

- Atención personalizada.

Utilizar iconos simples.

6. FOOTER

Footer minimalista con:

PcVex

"Componentes y periféricos para tu setup."

Enlaces:

- Inicio

- Productos

- Ofertas

- Contacto

- Políticas

Agregar iconos de redes sociales como placeholders.

Agregar copyright.

PÁGINA DE PRODUCTOS:

Crear una página sencilla con todos los productos.

Arriba:

"Productos"

Debajo:

"Encontrá componentes y periféricos para tu PC."

Mostrar los productos en una grilla.

Como actualmente habrá pocos productos, NO crear filtros complejos.

Solo incluir:

- Ordenar por precio.

- Ordenar por nombre.

PÁGINA DE PRODUCTO:

Crear una página individual sencilla.

Debe incluir:

- Imagen grande.

- Miniaturas.

- Nombre.

- Precio.

- Precio anterior si corresponde.

- Descripción corta.

- Disponibilidad.

- Selector de cantidad.

- Botón "Agregar al carrito".

- Botón "Comprar ahora".

- Información de envío.

- Especificaciones básicas.

- Productos relacionados.

Mantenerla limpia y fácil de entender.

CARRITO:

Crear un carrito sencillo.

Mostrar:

- Producto.

- Imagen.

- Precio.

- Cantidad.

- Subtotal.

- Total.

- Botón "Finalizar compra".

NO crear un sistema de checkout propio.

Dejar preparado para conectarlo posteriormente con el checkout nativo de Shopify.

CONTACTO:

Crear una página sencilla con:

"¿Tenés alguna consulta?"

Formulario:

- Nombre.

- Email.

- Mensaje.

Agregar también placeholders para:

- Instagram.

- WhatsApp.

- Email.

SHOPIFY:

Diseñar todo para que posteriormente pueda convertirse fácilmente a Shopify.

Utilizar componentes independientes:

- Header

- Footer

- ProductCard

- ProductGrid

- ProductPage

- Cart

- CategoryCard

- Button

Utilizar productos ficticios/mock data solamente para mostrar el diseño.

Posteriormente estos productos serán reemplazados por productos reales de Shopify.

Pensar en estas equivalencias:

Producto → Shopify Product

Categoría → Shopify Collection

Precio → Shopify Product Price

Precio anterior → Shopify Compare-at Price

Variantes → Shopify Product Variants

Carrito → Shopify Cart

Checkout → Shopify Checkout

NO crear:

- Base de datos propia para productos.

- Sistema de pagos propio.

- Checkout propio.

- Login complejo.

- Funciones innecesarias.

- Filtros avanzados.

- Blog.

- Newsletter.

- Pop-ups.

- Sistemas de membresía.

- Panel administrativo.

La prioridad es que PcVex sea rápida, sencilla y fácil de usar.

RESPONSIVE:

Optimizar especialmente para celulares.

Debe verse correctamente en:

- Celular.

- Tablet.

- PC.

PERFORMANCE:

- Código limpio.

- Imágenes optimizadas.

- Lazy loading.

- Animaciones mínimas.

- Evitar dependencias innecesarias.

RESULTADO FINAL:

Quiero que PcVex se vea como una tienda tecnológica nueva pero seria y confiable.

Debe sentirse:

"simple, moderna, tecnológica y profesional".

No quiero que parezca una empresa gigante con cientos de productos.

Quiero que el diseño funcione perfectamente aunque inicialmente solamente tengamos 5, 10 o 15 productos.
